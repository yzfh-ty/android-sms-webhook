## 当前实现

短信外发通道只支持企业微信群机器人文本消息。保留短信落盘、过滤、去重、重试、记录和 Root 诊断；0.3.0 新增手动维护的 eSIM 卡片与独立到期提醒，支持手机通知和企微。

| 功能 | 主要位置 |
| --- | --- |
| 企微地址校验、脱敏、错误码 | webhook/WebhookProtocol.kt |
| UTF-8 文本分段 | webhook/WecomMessageFormatter.kt |
| JSON POST、严格响应判定 | webhook/WebhookClient.kt |
| 快照、旧内容转换、重试 | data/RelayRepository.kt |
| URL 加密、旧配置迁移、共享节流 | data/SettingsStore.kt |
| 数据模型和 1 → 2 迁移 | data/RelayDatabase.kt |
| 任务领取、分段确认和续传 | delivery/WebhookWorker.kt |
| 短信接收和启动恢复 | receiver/、RelayApplication.kt |
| 原生页面 | ui/RelayApp.kt、RelayViewModel.kt |
| 本地企微模拟接口 | tools/dev_webhook.py |

Kotlin 目录为 `app/src/main/java/com/tyverse/smswebhook/`。数据库 schema 1、2 和 3 均保留在 `app/schemas/`，不使用破坏性重建。

## 0.3.0 eSIM 功能

新增 `esim/EsimData.kt`、`EsimRepository.kt`、`EsimPolicy.kt`、`EsimScheduler.kt` 与 `ui/EsimPage.kt`：

- 每张卡独立保存名称、加密资料与备注、到期时间、续期周期、提前量、重复间隔和渠道选择。
- 表单支持日期/时间选择、天/日历月周期、提醒开关与字段校验。手机时区作为卡片创建时区保存，暂不提供改时区界面。
- 续期必须确认，从确认时刻重新计算；使用资料修订号拒绝并发重复提交或过时编辑，用独立规则版本使旧提醒失效。备注编辑不重置提醒。
- 本地通知按卡片 ID 区分；权限或渠道不可用时保存受阻状态，恢复后重新检查。企微事件独立入队，复用机器人快照、节流和重试，默认不发送备注或号码。
- 暂停短信仅影响短信来源；卡片事件保留独立的开关和任务标签。旧卡片任务取消后不计入待处理容量。
- Room 2 → 3 新增卡片与事件表，并给投递记录增加卡片关联；保留 1 → 2 → 3 升级路径。

提醒扫描无需网络，企微发送单独等待网络。错过多个时段只生成一次当前提醒；有未完成事件时不堆积后续重复事件。后台调度和真机长期熄屏行为仍需实际设备验证。

UI 验证同时覆盖通知权限已授予和未授予时的页面布局。测试等待键盘关闭及临时“卡片已保存”提示结束，再点击页面下方操作，避免提示条遮挡触摸位置。

设备验证使用 Android 16 模拟器中的独立 `.qa` 包，保留正常应用的数据和配置；HTTP 请求只发送到本地 MockWebServer，没有访问真实机器人。

关键设备用例：

1. HTTP 200 + 非零 errcode 不记成功；缺失或错误 JSON 不记成功。
2. 45009 至少一分钟退避，-1 可重试，93000 需人工处理。
3. 请求不含通用认证/签名/幂等头，重定向不转发正文。
4. 长短信确认第一段、第二段失败后重试，第一段不重复提交。
5. 配置文件不包含明文机器人 key；旧明文地址与旧认证项正确迁移。
6. 根据真实导出的 schema 1 构建旧数据库，执行迁移后消息保留、新字段正确。
7. 并发任务共享持久化节流时刻，不同时获得同一个发送窗口。
8. 所有分段已确认但整条状态未落盘时，即使达到重试上限，也会完成任务而不重复发送。
9. 旧版只记录 HTTP 接受的任务显示“旧版完成”，不误计为已确认的企微发送成功。
