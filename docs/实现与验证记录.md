# 实现与验证记录

更新日期：2026-10-30。版本：0.2.0。主要目标：Android 16 / target API 36。

## 当前实现

通知通道只支持企业微信群机器人文本消息。保留短信落盘、过滤、去重、重试、记录和 Root 诊断，并替换原来的通用 Webhook 协议。

| 功能 | 主要位置 |
| --- | --- |
| 企微地址校验、脱敏、错误码 | webhook/WebhookProtocol.kt |
| UTF-8 文本分段 | webhook/WecomMessageFormatter.kt |
| JSON POST、严格响应判定 | webhook/WebhookClient.kt |
| 快照、旧内容转换、重试 | data/RelayRepository.kt |
| URL 加密、旧配置迁移、共享节流 | data/SettingsStore.kt |
| 数据模型和 1 → 2 迁移 | data/RelayDatabase.kt |
| 任务领取、分段确认和续传 | delivery/WebhookWorker.kt |
| 短信接收和启动恢复 | receiver/、RelayApplication.kt |
| 原生页面 | ui/RelayApp.kt、RelayViewModel.kt |
| 本地企微模拟接口 | tools/dev_webhook.py |

Kotlin 目录为 `app/src/main/java/com/tyverse/smswebhook/`。数据库 schema 1 和 2 均保留在 `app/schemas/`，不使用破坏性重建。

## 本次验证范围

- 单元测试：60 个通过，覆盖机器人 URL、凭证脱敏、错误分类、UTF-8 分段、过滤、指纹和退避。
- Android 16 独立 QA 包上的 30 个设备测试全量通过，包含界面、响应、迁移、节流和分段续传。UI 测试在启动界面前唤醒屏幕，避免模拟器休眠影响测试。
- Debug QA 构建和 Lint 通过；Lint 为 0 errors、24 warnings，主要是依赖更新、模板资源和按目标设备保留 target 36 的提示。
- 普通包名 Debug（versionCode 2 / 0.2.0）与未签名 Release 构建均通过，APK 保持 minSdk 26、targetSdk 36；构建结果未自动安装到正常应用中。

设备验证使用 Android 16 模拟器中的独立 `.qa` 包，保留正常应用的数据和配置；HTTP 请求只发送到本地 MockWebServer，没有访问真实机器人。

关键设备用例：

1. HTTP 200 + 非零 errcode 不记成功；缺失或错误 JSON 不记成功。
2. 45009 至少一分钟退避，-1 可重试，93000 需人工处理。
3. 请求不含通用认证/签名/幂等头，重定向不转发正文。
4. 长短信确认第一段、第二段失败后重试，第一段不重复提交。
5. 配置文件不包含明文机器人 key；旧明文地址与旧认证项正确迁移。
6. 根据真实导出的 schema 1 构建旧数据库，执行迁移后消息保留、新字段正确。
7. 并发任务共享持久化节流时刻，不同时获得同一个发送窗口。
8. 所有分段已确认但整条状态未落盘时，即使达到重试上限，也会完成任务而不重复发送。
9. 旧版只记录 HTTP 接受的任务显示“旧版完成”，不误计为已确认的企微发送成功。

## 先前版本已有验证

0.1.0 曾在 Android 16 模拟器完成系统模拟短信收信、普通进程退出后收信，以及断网落盘、进程退出后恢复网络补发。该历史结果证明基础接收和队列恢复链路，不替代本次企微接口及升级验证。

## 参考项目

本地参考 `tmp/SmsForwarder`，上游为 [pppscn/SmsForwarder](https://github.com/pppscn/SmsForwarder)，本地许可证为 BSD-2-Clause。核心源码独立编写，没有直接复制其业务实现。

主要参考短信接收器、规则模型、SendWorker、WeworkRobotUtils、KeepAliveUtils 和开机恢复入口。采用企微消息结构与 errcode 判定，并在本项目中增加加密地址、脱敏、字节分段、持久化进度和节流。开机恢复保持适配 Android 16 的有界调度方式，不直接拉起 Activity。

## 仍需真实环境验证

- 使用用户自己的机器人发送真实群通知，及其可能的网络/IP 访问限制。
- 真实手机运营商短信、双卡、验证码保护、24～72 小时熄屏和厂商后台策略。
- Magisk/KernelSU 授权、真实 ROM 上白名单添加和撤销。
- Android 8.0 最低版本兼容性与 Android 17 专项适配。
- 正式发行签名与发布；Release 文件未配置发行签名。

企业微信机器人没有客户端幂等保证，超时或确认落盘前退出仍可能重复。不会把模拟接口的成功当作真实群已收到通知。
